# 🌐 Language & Right-to-Left (RTL)

The loading screen speaks 12 languages, and Arabic and Urdu text renders right to left. The [Config Builder](https://loadingscreen.4zam.dev/builder.html) does this for you, with a live preview of the real loading screen.

[Open the Config Builder](https://loadingscreen.4zam.dev/builder.html){ .md-button .md-button--primary }
[Build with AI](https://loadingscreen.4zam.dev/ai.html){ .md-button }

Editing `config.json` by hand? Every option is in the Config reference: [`language`](config-reference.md#language) and [`keyboardShortcuts`](config-reference.md#keyboardShortcuts).

The builder writes `language` for you: pick a language in its settings menu and your export uses it. Your own text (rules, names, panel entries) is shown exactly as you wrote it.
