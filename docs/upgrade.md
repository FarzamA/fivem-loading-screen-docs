# 🔄 Upgrading to a New Version

This page moved to [Install & update: Updating to a new version](setup.md#updating).

The short version: back up `html/config.json` and your files in `html/assets/`, replace the resource with the new release and put them back. Or import your `config.json` into the [Config Builder](https://loadingscreen.4zam.dev/builder.html) and export a fresh resource.
