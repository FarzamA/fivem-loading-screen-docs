# 🧷 Social Header Configuration

Social cards link players to your Discord, store, YouTube and more. The [Config Builder](https://loadingscreen.4zam.dev/builder.html) does this for you under **Social Links**, with a live preview of the real loading screen.

[Open the Config Builder](https://loadingscreen.4zam.dev/builder.html){ .md-button .md-button--primary }
[Build with AI](https://loadingscreen.4zam.dev/ai.html){ .md-button }

Editing `config.json` by hand? Every option is in the Config reference: [`socialHeaders`](config-reference.md#socialHeaders).

---

## Custom icon support {#custom-icon-support}

Set a card's `type` to `custom` and give it your own icon with `imagePath`, sized with `imageWidth` and `imageHeight` (any CSS size such as `3vw`). In the builder, upload the icon and it is bundled into your download. Details: [`socialHeaders`](config-reference.md#socialHeaders).
