# ⌨️ Keyboard Overlay Configuration

The keyboard overlay highlights your server's keybinds, on foot and in a vehicle. The [Config Builder](https://loadingscreen.4zam.dev/builder.html) does this for you under **Keyboard**, with a live preview of the real loading screen.

[Open the Config Builder](https://loadingscreen.4zam.dev/builder.html){ .md-button .md-button--primary }
[Build with AI](https://loadingscreen.4zam.dev/ai.html){ .md-button }

Editing `config.json` by hand? Every option is in the Config reference: [`keyboardShortcuts`](config-reference.md#keyboardShortcuts).

In the builder you do not type key names: click a key field and press the key.
