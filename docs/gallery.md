# 🖼️ Gallery Panel Configuration

The Gallery panel shows your screenshots, and players can open them full size. The [Config Builder](https://loadingscreen.4zam.dev/builder.html) does this for you under **Gallery**, with a live preview of the real loading screen.

[Open the Config Builder](https://loadingscreen.4zam.dev/builder.html){ .md-button .md-button--primary }
[Build with AI](https://loadingscreen.4zam.dev/ai.html){ .md-button }

Editing `config.json` by hand? Every option is in the Config reference: [`gallery`](config-reference.md#gallery).
