# 🏷️ Watermark Configuration

The watermark is your server name, subheading and logo. The [Config Builder](https://loadingscreen.4zam.dev/builder.html) does this for you under **Brand & Color**, with a live preview of the real loading screen.

[Open the Config Builder](https://loadingscreen.4zam.dev/builder.html){ .md-button .md-button--primary }
[Build with AI](https://loadingscreen.4zam.dev/ai.html){ .md-button }

Editing `config.json` by hand? Every option is in the Config reference: [`watermark`](config-reference.md#watermark) and [`selectedColor`](config-reference.md#selectedColor).
