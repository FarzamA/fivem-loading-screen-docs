# 🧩 Custom Panel Configuration

Custom panels add your own tabs: updates, guides, jobs or anything else. The [Config Builder](https://loadingscreen.4zam.dev/builder.html) does this for you under **Custom Panels**, with a live preview of the real loading screen.

[Open the Config Builder](https://loadingscreen.4zam.dev/builder.html){ .md-button .md-button--primary }
[Build with AI](https://loadingscreen.4zam.dev/ai.html){ .md-button }

Editing `config.json` by hand? Every option is in the Config reference: [`customPanels`](config-reference.md#customPanels).
