# ✨ Title Animation

Pick how your server name animates, and turn the sweeping sheen on or off. The [Config Builder](https://loadingscreen.4zam.dev/builder.html) does this for you under **Brand & Color**, with a live preview of the real loading screen.

[Open the Config Builder](https://loadingscreen.4zam.dev/builder.html){ .md-button .md-button--primary }
[Build with AI](https://loadingscreen.4zam.dev/ai.html){ .md-button }

Editing `config.json` by hand? Every option is in the Config reference: [`watermark`](config-reference.md#watermark).

The options are `watermark.label.animation` (the preset) and `watermark.label.sheen`; the reference lists every preset.
